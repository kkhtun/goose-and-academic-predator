Add True/False, Word Search, and Crossword Interactive Boxes
The goal is to expand the current "Challenge" boxes (which only support Multiple Choice) to also support True/False, Word Search, and Crossword puzzles. The LLM will generate the question content based on the knowledge base, and the frontend will present an interactive UI for the user to solve it.

User Review Required
CAUTION

Dependencies: Generating Crossword layouts and Word Search grids robustly can be complex without dedicated libraries. My plan is to keep things simple:

Word Search: We can write a simple grid generator in the backend that hides a few words in a 10x10 grid. The frontend will render this grid, and users click the first and last letters of the words they find.
Crossword: Generating good intersecting crossword grids is computationally hard. We can either install a library like crossword-layout-generator for the backend to handle placement, or have the LLM return a simplified 5x5 grid. I recommend we install a library for layout generation if we want professional-looking crosswords.
Questions for you:

Are you okay with installing lightweight libraries for Word Search / Crossword generation (both frontend/backend)?
Do you want these new types to be mixed randomly with MCQs when a player lands on a Challenge box?
